# QAA_by_BNs

# Quality Assessment & BatchNorm Analysis

Этот репозиторий содержит реализацию методов оценки качества изображений лиц, основанных на анализе статистик слоёв Batch Normalization (BN). Код и теоретическая база опираются на две статьи:

1. Шокоров В.А., Самосюк А.В. *Разложение весов на интерпретируемые компоненты и их связь со статистиками слоя нормализации.*  
2. Шокоров В.А., Караев М.А., Самосюк А.В. *Слои нормализации по батчу как индикатор типичности обучающего домена.*  

В репозитории реализован практический пайплайн, который извлекает BN-признаки с помощью `KLDExtractor`, обучает регрессор CatBoost для предсказания косинусной близости к центроиду класса и оценивает качество на датасете IJB-C.

## Структура репозитория

## Пример использования

В `example.ipynb` представлен полный пайплайн обучения и тем=стирования алгоритма оценки качества изображения.

## Метод

1. **Извлечение BN-признаков.**  
   Для каждого изображения бэкбон возвращает эмбеддинг и вектор признаков, агрегированных по всем слоям BatchNorm. Эти признаки описывают распределение активаций в сети.

2. **Оценка типичности.**  
   Для каждого канала BN вычисляется симметричная KL-дивергенция между распределением признаков входного изображения и сохранёнными статистиками BN:

   $$
   D_{sKL}(F||BN) = \frac{1}{C} \sum_{c=1}^{C} \big[ D_{KL}(F_c||BN_c) + D_{KL}(BN_c||F_c) \big]
   $$

   Чем выше значение, тем менее типично изображение для обучающего домена.

4. **Регрессия качества.**  
   CatBoost обучается предсказывать косинусную близость эмбеддинга к центроиду класса. В качестве входных признаков используются агрегированные BN-статистики. Предсказанная близость используется как оценка качества.

## Результаты

На датасете IJB-C метод показывает эффективность фильтрации, сравнимую или превосходящую базовый подход (норма выходного вектора). Детальные таблицы и графики — в статьях и в `example.ipynb`.
